# 关键假设与已知事实

**本文件回答:"哪些是已知事实,哪些是为了让系统跑起来而做的仿真假设?"**
任何没有真实数据支持的参数都不得表述为"测得"。

## 已知事实(来自项目前期真实工作)

1. 项目最终目标是 32 通道太赫兹探测器阵列成像。
2. 探测器工作在零偏模式,输出为百 nA 级电流,经单通道 TIA 模拟前端转换为电压。
3. 模拟前端围绕 VREF 直流基准工作 → ADC 看到的是"基准 + 信号"的码,
   因此数字域的信号方向(ADC 码值随太赫兹辐射增强是升还是降)**取决于前端接法,不能写死**。
   本工程以 POLARITY 参数显式建模(±1,RTL 编译期参数 + 参考模型选项)。
4. 后续链路:探测器阵列 → 模拟前端 → ADC → FPGA → 成像 → 上位机显示。
5. 本阶段无真实探测器、ADC、FPGA 板卡,验证对象是数据链与处理逻辑本身。

## 仿真假设(全部由 tools/thz_config.py 集中定义,可一键修改)

| 参数 | 取值 | 假设依据 |
|---|---|---|
| 空间排布 | 4 行 × 8 列 = 32 像素 | 仅为 PoC 可视化方便,真实排布未定;通道映射已独立成表 |
| ADC 位宽 | 12-bit,范围 0~4095 | 常见中速 ADC 规格;真实选型未定 |
| ADC 中点码 | 2048 | 对应 VREF 基准的一半量程(假设) |
| 通道 offset 失配 | ±60 LSB(均匀分布) | 模拟 TIA 失调电压失配;量级为假设 |
| 通道 gain 失配 | ±25%(基础)/ ±45%(数据集10) | 模拟反馈电阻/跨阻失配;量级为假设 |
| 噪声 | 高斯 σ=8 LSB;low_snr 数据集 σ=25 | 假设;真实噪声需实测 PSD |
| 偶发尖峰 | 概率 0.5%,幅度 +800 LSB | 模拟读出毛刺;假设 |
| 坏点 | 数据集09:通道5 stuck-at 4095 | 模拟响应缺失像素 |
| 标定表 | dark = 基线+offset 的期望值;gain_q = round(256/gain) | "来自暗帧标定"的理想化替代;真实标定需实测暗场/均匀场 |
| 帧率/积分时间 | 未建模(仿真按拍同步) | PoC 不关注时序收敛,真实 ADC 接入时再定义 |
| 帧结构 | 每帧 = 32 个采样(逐通道串行) | 假设逐通道多路复用读出;真实读出方式未定 |

## 与真实硬件对接时必须替换/验证的清单

1. ADC 协议(SPI/LVDS 并口…)→ 在 `thz_input_adapter` 前加真实接口模块,管线零改动。
2. 帧同步方式(当前用 s_last 脉冲;真实系统可能是帧起始信号或 ADC 的 FRAMESYNC)。
3. 真实暗场/增益标定(采集暗场帧求平均替换 `data/calib/*.hex`)。
4. 噪声/失配参数用实测分布替换 thz_config.py 中的假设值。
5. 时钟域与 CDC(当前仿真单时钟域)。
