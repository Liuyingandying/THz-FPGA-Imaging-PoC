## 一、场景设计(16×32 ground truth 强度图,单位:nA)

| 场景 | 结构定义(16×32 网格) | 电流结构 |
|---|---|---|
| `rect_hole` | 矩形目标 rows4–11 × cols8–23(8×16),中心缺陷孔洞 rows7–8 × cols14–17(2×4) | 背景 50 / 目标(按档位)/ 缺陷 120 |
| `two_blocks` | 块 A rows2–5 × cols4–11,块 B rows10–14 × cols20–27(对角分离,各 4×8) | 背景 50 / 目标(按档位),无缺陷 |
| `letter_T` | 横杠 rows2–4 × cols8–23,竖杠 rows4–13 × cols14–17 | 背景 50 / 目标(按档位),无缺陷 |

对比机制假设(遮蔽式成像):目标区电流最高,背景(被遮蔽)最低,缺陷孔洞介于
两者之间。注意动态范围含义:在 L100 档,缺陷电流(120 nA)高于目标(100 nA),
"暗孔"语义不成立,孔洞呈现为中等亮区 —— 该档位考核的是**三值对比结构**的
可分辨性而非暗孔语义(见第四节)。

## 二、随机光电流模型

每通道每帧:

```
N      ~ Poisson(I_nA × E_PER_NA)          ← 光子到达统计(散粒噪声=计数固有方差)
adc    = clip(round(2048 + off_ch + gain_ch × LSB_PER_E × N + N(0, σ_read)), 0, 4095)
```

**物理机制(真实定律)**:Poisson 光子到达、散粒噪声方差=均值、通道失配存在、
ADC 量化、暗偏移逐通道存在且可被暗场标定扣除(其涨落不可扣除)。

**工程假设参数(非实测,集中定义于 scene512_validation.py,待实测替换)**:

| 参数 | 值 | 说明 |
|---|---|---|
| E_PER_NA | 60 e⁻/nA/帧 | 积分时间×量子效率的等效折算 |
| LSB_PER_E | 0.04 LSB/e⁻ | TIA 增益 × ADC 满量程折算 |
| σ_read | 3.0 LSB | 读出噪声(高斯) |
| 背景电流 | 50 nA | 含暗电流贡献(其 Poisson 涨落保留) |
| 目标电流 | 100 / 300 / 500 nA(动态范围三档) | 弱 / 中 / 强 |
| 缺陷电流 | 120 nA | 固定 |
| 通道失配 | offset ±60 LSB、gain ±25%(与 4×8 基线同分布,暗场/Q8 增益标定同机制) | 标定残差(Q8 截断)如实保留 |
| 帧数 | 4 帧 → 4 帧平均输出 1 帧 | 与 RTL AVG_FRAMES=4 一致 |
| 种子 | SEED+777 派生,场景/档位独立 | 全局可复现 |

生成过程中的两处模型缺陷已被指标异常捕获并修复:
① 原始数据漏注入通道暗偏移(±60 LSB),导致暗场扣除引入假固定图案
(rect_hole L100 的 r=0.83、背景 std=31.7 暴露)——真实硬件暗偏必然存在,
修复后 r=0.999;② 指标掩膜在目标电流低于缺陷电流时标签互换 —— 已改为
按电流值域定义。

## 四、重点问题回答

1. **16×32 两排拼接阵列下,系统是否还能恢复可解释的具体目标图像?**
   能。中/强档(L300/L500)下全部场景 Pearson r ≥ 0.9999、目标 IoU = 1.0,
   三个场景(矩形+孔洞、双分离块、字母 T)的重建图结构清晰可解释;
   弱档(L100)r 仍 ≥ 0.9987、IoU ≥ 0.94。且整条链路经真实 RTL 仿真,
   输出与黄金参考逐位一致 —— "可解释成像"不是插值美化,而是位级可溯的
   处理结果。

2. **缺陷孔洞是否还能分辨?**
   能,且余量充足。rect_hole 场景中缺陷区与背景、与目标的双侧对比余量在
   L100 档即达 +85σ / +24.7σ,L300 档为 +87.9σ / −224.8σ —— 在两个方向上
   都远超噪声,孔洞位置(rows7–8 × cols14–17)在重建图中明确可辨。

3. **不同电流水平下,恢复结果何时明显退化?**
   本参数组下 100–500 nA 全档未出现"明显退化":最弱档(L100,对比 SNR
   ≈ 35.6 dB)的 IoU 仍 ≥ 0.9375、NRMSE ≤ 0.048。退化趋势体现在相对量上
   (NRMSE 从 0.037→0.007,r 从 0.9993→1.0);若继续降档使对比 SNR 接近
   阈值分割的 ~3–5 dB 区间,预期先表现为孔洞边界像元失分、后整体 IoU
   崩塌 —— 该临界点可用本工具以更低 LEVELS_NA 直接扫描(参数即假设,
   替换即可重跑)。需要强调:以上 SNR 数值依赖工程假设参数
   (E_PER_NA/LSB_PER_E/σ_read),绝对值不代表真实样机;真实参数到位后
   以同一工具复测。

## 六、结论

在"两排 8×32 拼接为 16×32"的工程建模假设下:三个具体目标场景、三档动态
范围、共 9 组随机光电流数据集,经既有 RTL 管线(512 通道参数化实例)处理后,
输出与 Python 黄金参考**逐位一致(9/9)**;重建图像在全部档位可解释、目标
IoU ≥ 0.94、缺陷孔洞双侧对比余量 ≥ 24.7σ。系统在 16×32 规模下保持空间信息
恢复能力;板级实时链路的扩展点已列出,均不需要改动已验证的 RTL 算法核心。

## 九、Phase V3.1 失效边界研究(2026-10-02)

目标:不再生成高 SNR 漂亮图,而是找到当前系统的**失效边界**。
三个变量全部在数据/标定层注入(工具 `tools/v31_failure_boundary.py`,
结果 `results/v31/`);RTL/协议/Viewer 零改动。方法:统计用 Python 黄金
模型蒙特卡洛(与 RTL 位级一致性已由 9/9 证明),RTL 仿真在 ΔI 边界代表点
{30, 10, 5, 2.5} 做位级抽查 —— **四点全部 BIT-EXACT**。

### 9.1 变量 1:目标-背景电流差 ΔI(30 → 2.5 nA)

设置:BG=50 nA 固定,目标 = BG+ΔI,缺陷孔洞 = BG+ΔI/2(保持"孔洞"语义);
AVG=4;每点 8 次独立噪声实现 × 3 场景。

| ΔI (nA) | CNR | IoU 均值 | IoU 最小 | 缺陷检出率 |
|---|---|---|---|---|
| 30 | 37.07 | 0.9889 | 0.9449 | 1.000 |
| 20 | 24.40 | 0.9909 | 0.9449 | 1.000 |
| 15 | 18.45 | 0.9900 | 0.9449 | 1.000 |
| 10 | 12.47 | 0.9893 | 0.9524 | 1.000 |
| 7.5 | 9.48 | 0.9912 | 0.9600 | 1.000 |
| 5 | 6.25 | 0.9873 | 0.9597 | **0.375** |
| 3.5 | 4.35 | 0.9187 | 0.8630 | **0.000** |
| 2.5 | 3.25 | 0.7751 | 0.6604 | **0.000** |

**失效边界判定**(rect_hole,缺陷对比 = ΔI/2):
- **缺陷检出失效边界 ≈ ΔI 5–7.5 nA**:检出判据为缺陷与背景、与目标双侧
  余量均 ≥3σ;ΔI=5 nA 时检出率仅 0.375(过渡区),ΔI≤3.5 nA 时归零
  (缺陷对比只有 ΔI/2,其单侧余量先于目标分割失效);
- **目标分割失效边界 ≈ ΔI 3–3.5 nA**:ΔI≤2.5 nA 时 IoU 崩至 0.66–0.78
  (阈值分割在噪声中失稳),CNR≈3.3 为观测失效点。

### 9.2 变量 2:上下两排 8×32 标定后漂移失配(接缝研究)

建模:**标定后漂移**(bank2 相对 bank1 的增益漂移 g、偏置漂移 o,标称
标定表不含漂移)—— 对应真实场景"两排温漂/老化速率不同",是最不利且
真实的情况。场景 rect_hole(目标跨越接缝 rows7|8),ΔI=30,每组合
4 次实现。接缝不连续度 = 跨缝相邻行(row7↔row8)逐列差均值(以背景 σ
归一);对照 = 缝内正常相邻行差(ref)。

| gain 漂移 \ offset 漂移 | 0 LSB | 20 LSB | 40 LSB |
|---|---|---|---|
| 0% | 1.19σ / IoU 0.976 | 1.95σ / 0.968 | 1.98σ / 0.947 |
| 5% | 2.10σ / 0.966 | 2.10σ / 0.968 | 2.07σ / 0.911 |
| 10% | 2.40σ / 0.968 | 2.19σ / 0.968 | 2.11σ / 0.819 |
| 20% | 2.50σ / 0.968 | 2.29σ / 0.968 | 2.20σ / **0.662** |

**边界判定**:接缝跳变随漂移单调增长(基线 1.19σ → 极端组合 2.2–2.5σ);
目标 IoU 对**单一维度漂移相当鲁棒**(g≤20% 或 o≤40 LSB 时 IoU≥0.91),
但 **g=20% 且 o=40 LSB 组合时 IoU 跌至 0.662 —— 组合漂移是真实失效点**。
工程含义:双排结构的标定必须分排进行(排级标定可完全吸收此类失配),
且需限定排间温漂预算(经验上 gain<10% 且 offset<40 LSB 时成像质量无实质
影响)。

### 9.3 变量 3:AVG_FRAMES = 1/2/4/8/16(ΔI=10 nA,边界区)

| AVG | CNR | 背景 σ (LSB) | 目标 IoU | 有效帧率(板级 UART 上限) |
|---|---|---|---|---|
| 1 | 6.43 | 3.73 | 0.984 | 11.2 fps |
| 2 | 8.91 | 2.72 | 0.986 | 5.6 fps |
| 4 | 12.31 | 1.93 | 0.984 | 2.8 fps |
| 8 | 17.06 | 1.41 | 0.987 | 1.4 fps |
| 16 | 22.91 | 1.05 | 0.990 | 0.7 fps |

**延迟/质量权衡**:CNR 近似按 √N 增长(6.4→22.9),但背景噪声存在
**固定图案底板**(~1 LSB,平均无法消除,来自标定残差)——N≥8 后收益
递减(σ 从 1.41→1.05 仅再降 26%)。板级有效帧率 = 11.2/N fps(UART
带宽上限)。工程结论:**AVG=4 是检测任务的性价比点**(CNR 翻倍、帧率
2.8 fps 足够);AVG=16 仅适合静态/慢变目标的极限灵敏度模式。

### 9.4 失效边界汇总

| 失效模式 | 边界 | 先兆指标 |
|---|---|---|
| 缺陷孔洞不可检出 | ΔI < ~7.5 nA(检出率<1);ΔI ≤ 3.5 nA 检出率 0 | 缺陷双侧余量 <3σ 先于 IoU 崩塌 |
| 目标分割失效 | ΔI ≲ 3 nA(IoU<0.9);≤2.5 nA 崩塌(0.66–0.78) | CNR ≈ 3–4.4 |
| 双排组合漂移失效 | g=20% 且 o=40 LSB(IoU 0.662) | 接缝跳变 >2σ |
| 平均收益枯竭 | N≥8(固定图案底板 ~1 LSB) | σ 不再按 1/√N 下降 |
